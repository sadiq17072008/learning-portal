🧠 Important Trigonometry Formulas

1. Sine

sin θ = Opposite / Hypotenuse
2. Cosine

cos θ = Adjacent / Hypotenuse
3. Tangent

tan θ = Opposite / Adjacent
4. Reciprocal Ratios

cosec θ = 1/sin θ
sec θ = 1/cos θ
cot θ = 1/tan θ
5. Pythagorean Identity

sin²θ + cos²θ = 1
6. Tangent Identity

1 + tan²θ = sec²θ
7. Cotangent Identity

1 + cot²θ = cosec²θ
8. Complementary Angles

sin(90° − θ) = cos θ
cos(90° − θ) = sin θ
tan(90° − θ) = cot θ

📊 Standard Trigonometric Values

sin θ

sin 0° = 0
sin 30° = 1/2
sin 45° = 1/√2
sin 60° = √3/2
sin 90° = 1
cos θ

cos 0° = 1
cos 30° = √3/2
cos 45° = 1/√2
cos 60° = 1/2
cos 90° = 0
tan θ

tan 0° = 0
tan 30° = 1/√3
tan 45° = 1
tan 60° = √3
tan 90° = Undefined

✏️ Solved Numerical Examples

Example 1: In a right triangle, the opposite side is 3 cm and the hypotenuse is 5 cm. Find sin θ.

sin θ = Opposite / Hypotenuse
sin θ = 3/5
Answer = 3/5
Example 2: Find the value of tan 45°.

tan 45° = 1
Example 3: Find sin 30° + cos 60°.

sin 30° = 1/2
cos 60° = 1/2
Therefore,
1/2 + 1/2 = 1
Example 4: If sin θ = 3/5, find cos θ for an acute angle θ.

sin²θ + cos²θ = 1
(3/5)² + cos²θ = 1
9/25 + cos²θ = 1
cos²θ = 16/25
cos θ = 4/5
Example 5: If tan θ = 3/4, find sin θ.

Consider opposite = 3 and adjacent = 4.
Hypotenuse = √(3² + 4²)
= √25 = 5
Therefore,
sin θ = 3/5
Answer = 3/5
Example 6: A pole is 10 m high. If the angle of elevation from a point on the ground is 45°, find the distance of the point from the pole.

tan 45° = Height / Distance
1 = 10 / Distance
Distance = 10 m
