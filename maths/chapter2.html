🧠 Important Formulas

1. Arithmetic Progression
A sequence in which the difference between consecutive terms is constant is called an arithmetic progression.
2. Common Difference
d = a₂ − a₁
More generally,
d = aₙ − aₙ₋₁
3. nth Term of AP
aₙ = a + (n − 1)d
where a is the first term and d is the common difference.
4. Sum of n Terms of AP
Sₙ = n/2 [2a + (n − 1)d]
5. Alternative AP Sum Formula
Sₙ = n/2 (a + l)
where l is the last term.
6. Geometric Progression
A sequence in which the ratio between consecutive terms is constant is called a geometric progression.
7. Common Ratio
r = a₂ / a₁
8. nth Term of GP
aₙ = arⁿ⁻¹
9. Sum of n Terms of GP
For r ≠ 1,
Sₙ = a(rⁿ − 1)/(r − 1)
10. Sum of First n Natural Numbers
1 + 2 + 3 + ... + n = n(n + 1)/2
11. Sum of Squares
1² + 2² + ... + n² = n(n + 1)(2n + 1)/6
12. Sum of Cubes
1³ + 2³ + ... + n³ = [n(n + 1)/2]²

✏️ Solved Numerical Examples

Example 1: Find the common difference of 7, 12, 17, 22, ...

d = 12 − 7
d = 5
Example 2: Find the 10th term of 3, 7, 11, 15, ...

a = 3
d = 4
n = 10
aₙ = a + (n − 1)d
= 3 + 9(4)
= 39
Example 3: Find the sum of the first 20 natural numbers.

S₂₀ = 20(21)/2
= 210
Example 4: Find the 8th term of the GP 2, 6, 18, 54, ...

a = 2
r = 3
n = 8
a₈ = 2 × 3⁷
= 4374
Example 5: Find the sum of the first 10 terms of 2, 4, 6, 8, ...

a = 2
d = 2
n = 10
S₁₀ = 10/2 [2(2) + 9(2)]
= 5(22)
= 110
