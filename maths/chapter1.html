🧠 Important Concepts

1. Ordered Pair
An ordered pair is written as (a,b).
The first element is called the first coordinate and the second element is called the second coordinate.
2. Cartesian Product
If A and B are two sets, then

A × B = {(a,b) : a ∈ A and b ∈ B}
3. Number of Elements
If n(A) = m and n(B) = n, then

n(A × B) = mn
4. Relation
A relation from A to B is a subset of A × B.
5. Domain
The set of all first components of ordered pairs in a relation is called its domain.
6. Range
The set of all second components of ordered pairs in a relation is called its range.
7. Function
A relation from A to B is a function if every element of A is associated with exactly one element of B.
8. One-One Function
Different elements of the domain have different images.
9. Many-One Function
Two or more elements of the domain may have the same image.
10. Onto Function
Every element of the codomain has at least one pre-image.

✏️ Solved Numerical Examples

Example 1: If A = {1,2,3} and B = {4,5}, find n(A × B).

n(A) = 3
n(B) = 2
Therefore,
n(A × B) = 3 × 2 = 6
Example 2: If A = {1,2} and B = {3,4,5}, find A × B.

A × B = {(1,3),(1,4),(1,5),(2,3),(2,4),(2,5)}
Example 3: If R = {(1,2),(2,4),(3,6)}, find the domain and range.

Domain = {1,2,3}
Range = {2,4,6}
Example 4: If f(x) = 2x + 3, find f(5).

f(5) = 2(5) + 3
= 10 + 3
= 13
Example 5: If f(x) = x² + 2, find f(3).

f(3) = 3² + 2
= 9 + 2
= 11
